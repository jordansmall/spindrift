## [0.32.0](https://github.com/jordansmall/spindrift/compare/v0.31.0...v0.32.0) (2026-11-18)


###   BREAKING CHANGES

* **dispatch:** a read-only Box no longer receives GH_TOKEN, FORGEJO_TOKEN, BOX_GH_TOKEN or BOX_FORGEJO_TOKEN, and forge.boxForgeCredential = "forwarded" no longer forwards one. See MIGRATING.md.
* **sdk:** Strategy.NewDecoder in spindrift.dev/sdk/driver is now func(now time.Time) Decoder instead of func() Decoder. A Connector built on the SDK takes the extra argument (or ignores it). The wire protocol stays at 0.3.0, which has not shipped in a release.
* **harness:** a Consumer that never set BOX_FORGE_AND_ISSUE_ACCESS now runs read-only. On github and forgejo that needs a distinct, read-scoped Box token; set the knob to read-write explicitly to keep the old behaviour for now (it warns as deprecated). See MIGRATING.md.
* **connectorhost:** core refuses a Connector declaring protocol 0.1.x.
* **connectorhost:** core refuses a Connector declaring protocol 0.0.x.
