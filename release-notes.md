###   BREAKING CHANGES

* **harness:** a Consumer that never set BOX_FORGE_AND_ISSUE_ACCESS now runs read-only. On github and forgejo that needs a distinct, read-scoped Box token; set the knob to read-write explicitly to keep the old behaviour for now (it warns as deprecated). See MIGRATING.md.
* **connectorhost:** core refuses a Connector declaring protocol 0.1.x.
* **connectorhost:** core refuses a Connector declaring protocol 0.0.x.
