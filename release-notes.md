## [0.11.0](https://github.com/jordansmall/spindrift/compare/v0.10.0...v0.11.0) (2026-08-17)


###   BREAKING CHANGES

* **versioning:** agent-trigger is no longer part of the versioned label lifecycle contract in VERSIONING.md. It may change name in a future non-major release; the label's own runtime behavior in agent-dispatch.yml is unaffected.
* **mkHarness:** a direct mkHarness caller passing a choices-bearing knob's default = null now fails eval (previously silently accepted and rendered as an empty string, e.g. MERGE_METHOD=""). See MIGRATING.md.
* **mkHarness:** mkHarness now throws if a choices-bearing knob's merged default is not a member of its declared choices. A direct mkHarness caller (bypassing the flake module) passing an invalid value, e.g. mkHarness { defaults.mergeMethod = "Auto"; }, previously rendered silently into the Launcher input document; it now fails eval instead. See MIGRATING.md.
* **flakeModule:** Consumer flake options for the seven choices-bearing knobs (mergeMode, codeForge, issueTracker, overlapGate, mergeMethod, syncMethod, boxForgeAndIssueAccess) now use types.enum instead of types.str. A Consumer setting one to a value outside its choices list (e.g. git.merge.policy = "Auto") now fails nix eval instead of evaluating. See MIGRATING.md.
* **entrypoint:** REVIEW_EFFORT/--review-effort no longer take effect as a live, per-dispatch Box-runtime override -- setting either at dispatch time is now a silent no-op. The value now reaches the orchestrator only through the nix-baked roster reviewer entry's own effort (settings.models.reviewEffort, image rebuild required), the same shape REVIEW_MODEL already has. Under DRIVER=opencode specifically, whose agentsJsonTemplate never renders a reviewer key, the review pass now always falls back to the coordinator's own effort -- matching REVIEW_MODEL's existing opencode fallback. See MIGRATING.md.
